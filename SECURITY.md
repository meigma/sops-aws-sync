# Security Policy

## Supported Versions

Only the latest published `sops-aws-sync` release is supported.

## Reporting a Vulnerability

Report vulnerabilities through GitHub private vulnerability reporting for `meigma/sops-aws-sync`.

Do not use public issues, pull requests, discussions, chat channels, or other public forums for vulnerability reports. Include the affected version or commit, impact, reproduction steps, and any suggested mitigation when available. Never attach real secret material, AWS credentials, decrypted SOPS content, or KMS data to a report.
